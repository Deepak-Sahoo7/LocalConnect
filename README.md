# LocalConnect

## Smart Local Service Finder

LocalConnect is a smart local service finder that helps users discover nearby services, make online bookings, and receive SMS notifications.

## Features

- Find local services
- Discover nearby service providers
- Online booking
- SMS booking notifications
- Responsive web interface
- Backend API integration

## Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
- REST API
- Twilio SMS
